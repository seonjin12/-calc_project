# 계산기 프로젝트

## 1. 기능 소개

- **더하기**
```python
def sum(a, b):
    return a + b
```

- **빼기**
```python
def sub(a, b):
    return a - b
```

- **곱하기**
```python
def mul(a, b):
    return a * b
  ```

- **나누기**
```python
def div(a, b):
    return a / b
  ```

- **제곱**
```python
def square(a, b):
    return a ** b
```
